# ADR 0024: Repeatable current-feature pitch, not production provisioning

Date: 14 October 2026. Scope: the current-feature rehearsal slice of #97.

Use a fresh marked private destination with current Development startup migrations and existing
Identity seed flows. Generate all four seed passwords, the invited employee's password and signing/
refresh material privately. Create the demonstrated employee through the actual HR CSV preview/
confirmation and anonymous activation form, never direct SQL provisioning or an auth bypass.
No production source, schema, role rules or dependencies change.

The Node operator tool forces Development, validates destination ownership/reparse ancestors,
rejects existing setup destinations, bounds scanner/API readiness and owns its API/Vite lifetimes.
It resolves the actual seeded Manager department through the HR API because query order is not a
stable seed-department contract. Cleanup refuses live parent/API PIDs and removes only marked
synthetic storage and the unique private pickup profile. Abrupt OS termination still needs ownership
inspection; no broad process/temp-root deletion or automatic recovery of real stores is supported.

Real local ClamAV is required. VERSION is only readiness; clean evidence is established by the
application's real INSTREAM scanning, immutable checksum verification and protected binding. The
fixture is a complete harmless ordinary PDF, not medical evidence. No always-clean substitute or
production invitation provider is introduced. Definitions must be operationally maintained.
[Official protocol](https://docs.clamav.net/manual/Usage/ClamdProtocol.html), checked 14 October 2026.

The runner reuses existing Playwright dependencies for actual browser actions against actual HTTP,
including onboarding, activation, HR company requirements, upload, submission, Manager note decision,
owner timeline/inbox, team view and HR reports/export. Explicit inbox refresh allows asynchronous
outbox delivery to become visible without claiming instant cross-account updates. Persisted audits,
actors, document bytes/checksum/binding and event recipients supplement UI evidence. Direct API 403
checks demonstrate HR/no-self-decision boundaries without showing bearer tokens to the audience.

Dates are captured at fresh setup using Africa/Johannesburg. Restart preserves records and the
captured scenario; a different business date requires a fresh destination, not silent rewrites.
Leave remains inclusive calendar days. Fixed company entitlement is not statutory annual accrual;
Medical Required is unsupported pending absence/payment work. No diagnoses, notes or documents
are copied into notifications/report summaries. Screenshot capture excludes login, activation and
browser chrome; only reviewed synthetic protected pages are eligible.

The 9-minute speaking runbook is a proposed presentation duration, not a measured human pitch.
Automated elapsed time, local regression results, failed fixture experiments and remaining limits
are recorded separately. Hosted GitHub/Linux/Chromium is billing-blocked; no spending, workflow
disablement, branch-protection weakening or deployment is authorised. #97 stays open for its full
dependencies, including qualified legal/calculation and broader reliability/production gates.
