## Encrypted recovery

The retained offline case creates a new migrated private store and random separately stored key.
It backs up/restores Current, Processing and Removed image rows, compares current ID/version/hash,
verifies exact restored bytes and the persistent removal marker, and proves a removed ID cannot
publish. Missing current content makes backup fail. A generated Identity account's password is
cleared and credential version rotated on recovery; active/activation state is preserved.

This is local Windows image-coherence/security-state evidence, not a restored all-role browser
matrix. Package format stays 1; exact application migration compatibility is still required.
No database/private file was committed. Rollback drops image metadata and leaves inaccessible
private objects requiring reviewed image-only reconciliation; bound leave evidence is unchanged.
